# Delest — site

Site vitrine, politique de confidentialité et conditions d'utilisation de Delest (français et anglais), publiés par
GitHub Pages : https://kdev1966.github.io/delest-site/

Les paquets d'installation (macOS, Windows, Linux) sont attachés aux releases de ce dépôt. Le code de l'application
n'est pas dans ce dépôt.

Pages en HTML et CSS, sans JavaScript ni police chargée ailleurs, dans la charte graphique de l'application.
