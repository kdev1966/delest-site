# Delest — site

Site vitrine, politique de confidentialité et conditions d’utilisation de Delest, en anglais par défaut (à la racine) et en français (`fr/`), publiés par
GitHub Pages : https://kdev1966.github.io/delest-site/

Les paquets d’installation sont attachés aux releases du dépôt de Delest : https://github.com/kdev1966/Delest (open source,
licence MIT). Le code de l’application n’est pas dans ce dépôt.

Pages en HTML et CSS, sans JavaScript ni police chargée ailleurs, dans la charte graphique de l'application.
