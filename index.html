The core

The Arbiter, at the heart of Delest

A typical cleaner deletes whatever looks like a cache. Delest does the opposite: it only proposes what it can prove rebuilds, and it shows you the proof.

Only what rebuilds

target, node_modules, build, .gradle, .venv, Pods, .next: recognised by their manifest and lockfile, never by their name alone.

Every verdict explained

Ignored by git, next to its manifest, last commit three days ago: every proposal comes with its reasons.

Absolute bans

Work git does not track, tracked files, secrets (.env, .pem), source code and Docker volumes are never proposed.

Nothing leaves without you

A preview, your consent, then the quarantine: seven days to restore anything, before the final deletion.

Your stack

Recognised by its manifest, not by its name

A folder is proposed only when the file that rebuilds it sits next to it. The rules in shadow already recognise their folders and propose nothing until the corpus accepts them.

The Brain

A Brain that learns from you, only towards caution

Delest's Brain weighs the rules, your project's context and your past decisions. The local model is a voice it listens to on unknown folders, never the one that decides.

  • It works without a modelRules, bans, context and memory decide. The model only helps on folders no rule knows.
  • Your refusals teach itA folder you refuse three times is no longer proposed.
  • A restore is a lessonA folder you put back from the quarantine goes back to “to review”; two restores of one rule's folders put the whole rule in doubt. Remembered for 90 days.
  • It knows what you work onDependencies of a project with a commit in the last 30 days are kept: reinstalling them would cost you now. Handoff, when present, tells it too.
  • Learning never lifts a banHabits only ever make Delest more careful: nothing it learns makes a protected folder deletable.
  • The model cannot say “deletable”Its answers are bound by a grammar to “keep” or “to review”. It runs only when memory and battery allow, and every opinion is written to a journal.
Your agents

One command, and your agents watch the disk

At each session, Delest checks the free space and stays quiet unless the disk is filling up. Through MCP, your agents can ask it themselves.

Hooks in your agents

A check at session start in Claude Code, Codex, Cursor, Gemini CLI, VS Code (Copilot) and OpenCode; Kiro through Vario. In the app: Settings › A check at each agent session, one button per agent. In a terminal: delest install, and delest remove takes them out. Each file is backed up.

Three MCP tools, read-only

delest_status (the disk and what can be freed), delest_explain (the reasons for one folder), delest_scan (what can be freed in folders you name).

Ask your agent, on a click

For a folder you are unsure of, the app can put your question to Claude Code: the folder's path and the names of what it holds, never the files.

# the hooks, from a terminal
delest install

# Delest as an MCP server for Claude Code
# Linux (.deb) or Cargo
claude mcp add delest -- delest mcp
# macOS
claude mcp add delest -- /Applications/Delest.app/Contents/MacOS/delest mcp
# Windows (PowerShell)
claude mcp add delest -- "$env:LOCALAPPDATA\Delest\delest.exe" mcp

With the macOS or Windows app, delest stays inside the app: give its full path, as above, or install the command with Cargo.

Privacy

Your code stays with you

Delest reads folder names and facts (size, git state, nearby manifests). It does not open your files to send them anywhere.

  • No account, no ads, no analytics.
  • The AI models run on your machine, offline.
  • “Ask the agent” sends only the folder's path and the names of what it holds, and only when you click.
  • Everything Delest does is written to a journal, on your machine.

FAQ

Questions

Does Delest delete anything on its own?

No. It proposes, you choose, then the folders go into the quarantine for seven days. Nothing is deleted without your consent.

What if I need a quarantined folder back?

Restore it from the Quarantine page, or with delest restore, within seven days. After that, it is deleted.

Do I need an AI agent to use Delest?

No. The app and the command work on their own; agents only add a check at each session.

What does Delest do with a folder it does not recognise?

It does not propose it. The local model can give an opinion, always towards caution, and the decision is yours.

Does Delest download AI models on its own?

No. Delest works without them. In Settings › AI, “Install the local AI” shows what it would download (about 3.2 GB), and fetches it only after you confirm; each file is checked against its published fingerprint. The engine needs macOS 13.3 or later, and on Windows a recent Visual C++ runtime.

How much does Delest cost?

Nothing. Delest is free and open source, under the MIT licence: its code is on GitHub.
